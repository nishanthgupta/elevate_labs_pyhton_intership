# To-Do List Application (Python)

## About
A simple console-based To-Do List application developed using Python. It helps users manage daily tasks.

## Features
- Add new tasks
- View all tasks
- Remove tasks
- Save tasks in a text file
- Load previously saved tasks

## Technologies Used
- Python
- VS Code
- File Handling (.txt)

## How to Run
1. Download or clone the repository.
2. Open the project in VS Code.
3. Run the following command:

```bash
python todo.py
```

## Files
- `todo.py` – Main Python application.
- `tasks.txt` – Stores saved tasks.
